🥷 Stealth Professional Tip

Always interact with the app using Global Hotkeys. Clicking on the window during a proctored exam may trigger focus-detection alerts from monitoring software.

📸 Multi-Screenshot Analysis

You can capture multiple screenshots with Ctrl+Shift+Win+S to build a queue, then process them all at once with Ctrl+Shift+Win+P. This is highly recommended for complex multi-part coding questions.

⚡ Speed Strategy

If your primary AI model is lagging, use Ctrl+Shift+Win+E to immediately trigger Auto-Select. VeyraCue will switch you to the fastest healthy provider available.
